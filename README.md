# 🛡️ VPN Configs Hub

Добро пожаловать в репозиторий с готовыми конфигурациями для обхода блокировок. 
Все настройки маскируют трафик под обычный HTTPS (WebSocket + TLS / REALITY), что делает их незаметными для DPI [citation:1].

## 📥 Быстрый старт

### Для приложения v2rayTun (Android)
1. Скачайте приложение v2rayTun из магазина.
2. Скачайте файл конфигурации из папки [/configs/v2raytun/](/configs/v2raytun/).
3. В приложении нажмите + -> Импорт из файла и выберите скачанный файл [citation:1].
4. Нажмите "Подключить".

### Для приложения Happ (iOS)
1. Скачайте приложение Happ.
2. Скопируйте ссылку на любой конфиг из папки [/configs/happ/](/configs/happ/).
3. В приложении нажмите "Добавить конфигурацию" и вставьте ссылку.

## 📁 Структура
- configs/v2raytun/ - готовые JSON-файлы.
- configs/share/ - ссылки вида vless://... для ручного ввода.
- subscriptions.txt - ссылка на автоматическую подписку.

## ⚠️ Важно
Некоторые конфиги могут не работать с определенными операторами связи. 
Если один не работает — попробуйте другой [citation:1].
